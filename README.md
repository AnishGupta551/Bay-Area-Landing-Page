# Empowerly — Regional Events
 
## About Empowerly
 
Empowerly is an ed-tech college counseling company that provides students with personalized guidance through the college admissions process and beyond.
 
## About this project
 
This project adds a regional **Events** section to the Empowerly website. A new Events dropdown is added to the end of the main navigation bar, containing a category for each region. Each region links to its own landing page hosted on empowerly.com, with Luma embedded to handle event listings and registration.

## Styling

`Empowerly CSS.css` contains the extracted stylesheet from the live Empowerly website. All landing pages built in this project should reference and follow this stylesheet to stay visually consistent with the rest of the site — use existing classes and tokens rather than writing new styles from scratch.
